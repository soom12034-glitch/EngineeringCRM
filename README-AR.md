# تطبيق مستقل لإدارة العملاء
هذه النسخة مخصصة لـ أعمال المساحة.
بيانات المنشأة والعملاء تدخل من الواجهة وتخزن داخل مساحة التطبيق على الهاتف، ولا تحتوي حزمة المصدر على بيانات منشأة أو شعارها أو قاعدة بياناتها أو مفتاح توقيع.
البناء: Android SDK 36 وJava 17 وGradle. هوية التطبيق مستقلة؛ تثبت النسختان بجانب بعضهما وبجانب التطبيق القديم.
أوامر التحقق: شغّل `gradlew.bat check` على Windows أو `./gradlew check` على Linux/macOS. يقوم Gradle Wrapper بتنزيل Gradle 8.11.1 الموثق ببصمة SHA-256، ثم يشغّل اختبارات Java واختبارات ترحيل SQLite المكتوبة بـ Python.
نقل البيانات: صدّر نسخة احتياطية من التطبيق القديم، ثم استعدها في هذه النسخة؛ تُستورد بيانات النشاط المناسب فقط. صنّف العملاء غير المحددين في التطبيق القديم قبل التصدير. تبقى ملفات النسخ الاحتياطية خاصة؛ لا ترسلها مع المصدر.
المساحة: أدخل بيانات المنشأة في الإعدادات وبيانات نموذج عرض السعر من شاشة العروض؛ لا يوجد شعار مؤسسة مضمّن.
أندرويد يسمح بتطبيق واحد فقط لدور تحديد المتصل؛ اختر النسخة التي تريد أن تستقبل المكالمات الجديدة. استيراد السجل يخضع لإذن الهاتف.
